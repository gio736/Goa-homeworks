1. დედამიწაზე უამრავი საოცარი და ჯერ კიდევ შეუსწავლელი ადგილი არსებობს.

2. ოკეანეების უდიდესი ნაწილი ადამიანისთვის კვლავ იდუმალებით არის მოცული.

3. ყოველდღიურად ბუნებაში უამრავი საინტერესო მოვლენა ხდება ჩვენ გარშემო.

4. ცხოველთა სამყარო ყოველთვის გვაოცებს თავისი მრავალფეროვნებითა და სილამაზით.

5. პირველი თავგადასავალი აქ მთავრდება, თუმცა წინ ბევრი საინტერესო ამბავია.

1. კოსმოსი წარმოუდგენლად დიდია და მასში მილიარდობით გალაქტიკაა მოქცეული.

2. ვარსკვლავები, რომლებსაც ღამით ვხედავთ, ხშირად ჩვენგან ძალიან შორს იმყოფებიან.

3. მეცნიერები მუდმივად ცდილობენ ახალი პლანეტებისა და სისტემების აღმოჩენას.

4. ღამის ცაზე ყურება ყოველთვის აღძრავს ჩვენში დიდ ინტერესსა და ცნობისმოყვარეობას.

5. კოსმოსური მოგზაურობა მომავალში შესაძლოა ჩვეულებრივ მოვლენად იქცეს.

1. ჯანსაღი ცხოვრების წესი გვეხმარება ენერგიისა და კარგი განწყობის შენარჩუნებაში.

2. დილით ადრე გაღვიძება და ვარჯიში მთელი დღის მანძილზე პროდუქტიულს გვხდის.

3. სუფთა წყლის სმა ორგანიზმისთვის ერთ-ერთი ყველაზე სასარგებლო ჩვევაა.

4. ბუნებაში ხშირი გასეირნება ამცირებს სტრესს და გვივსებს ძალებს.

5. საკუთარ ჯანმრთელობაზე ზრუნვა ყოველდღიურად უნდა ვაქციოთ პრიორიტეტად.

1. წიგნების კითხვა საუკეთესო გზაა ახალი სამყაროებისა და იდეების აღმოსაჩენად.

2. ყოველი ახალი გვერდი გვაძლევს შესაძლებლობას ვისწავლოთ რაღაც განსხვავებული.

3. ლიტერატურა ავითარებს ფანტაზიას და გვეხმარება სამყაროს უკეთ გაგებაში.

4. ბევრი ადამიანი კითხვით იწყებს ან ასრულებს თავის დატვირთულ დღეს.

5. კარგი წიგნი მუდამ საუკეთესო მეგობარი და მრჩეველია ნებისმიერ დროს.

1. ტექნოლოგიური პროგრესი ყოველდღიურად ცვლის ჩვენს ცხოვრებას უკეთესობისკენ.

2. დღესდღეობით ინფორმაციის მიღება და გაზიარება წამებშია შესაძლებელი.

3. ახალი პროგრამები და ხელსაწყოები საქმეს ბევრად უფრო მარტივს ხდის.

4. საინტერესოა იმის წარმოდგენა, თუ როგორი იქნება ჩვენი სამყარო მომავალში.

5. მთავარია, სიახლეებს ყოველთვის ინტერესითა და მონდომებით შევხვდეთ.
